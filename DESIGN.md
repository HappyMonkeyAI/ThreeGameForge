# ThreeGameForge Design

The framework playground should feel like a calm technical forge: dark, legible, responsive, and diagnostic without becoming a game-specific HUD.

Design principles:

- Make runtime state observable.
- Prefer representative playable slices over static demos.
- Keep debug presentation separate from product presentation.
- Establish camera scale and visual budgets before adding effects.
- Use procedural visuals for framework fixtures; reserve authored assets for consumer games.
