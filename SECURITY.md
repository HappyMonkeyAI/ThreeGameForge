# Security policy

Please do not report security vulnerabilities in a public issue.

Use GitHub’s private vulnerability reporting for this repository when it is
available. If private reporting is unavailable, contact the repository owner
through GitHub and include only the minimum information needed to reproduce the
issue. Do not include credentials, personal data, or production access details.

The project is an early framework and is not intended for production use until
its package-release and security-review tasks are complete.
