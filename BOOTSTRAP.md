# ThreeGameForge Protocol Bootstrap

Bootstrap follows the HappyMonkeyAI AgentsProtocol model:

1. Read `CONTEXT.md`, `ARCHITECTURE.md`, `DESIGN.md`, `SPEC.md`, `PLAN.md`, and `TASKS.md`.
2. Inspect the current Git state and preserve existing user changes.
3. Map dependencies and ownership before changing shared contracts.
4. Keep durable insights in `.agent/memories/`.
5. Track work in `TASKS.md` and `.agent-tasks.json`.
6. Verify with the applicable test, build, browser, and performance gates.
7. Record failures and lessons before continuing after a correction.

This repository intentionally requires explicit human approval for commits, pushes, destructive Git operations, paid asset generation, and external deployment.
